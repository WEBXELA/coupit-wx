## Project Information

Coupit is an AI-powered retail solution designed to bridge the gap between physical and digital retail. Our platform offers a range of features to enhance customer engagement, optimize inventory, and boost sales.

### Features

- AI-Powered Analytics: Get real-time insights into customer behavior, campaign performance, and sales trends.
- Interactive Displays: Engage customers with beautiful, interactive displays that drive action.
- Gamified Rewards: Turn shopping into an engaging experience with instant rewards.

## Installation Instructions

To get started with Coupit, follow these steps:

1. **Clone the repository**:
   ```sh
   git clone https://github.com/WEBXELA/coupit-wx.git
   ```

2. **Navigate to the project directory**:
   ```sh
   cd coupit-wx
   ```

3. **Install dependencies**:
   ```sh
   npm install
   ```

4. **Start the development server**:
   ```sh
   npm run dev
   ```

## Usage Guidelines

Once the development server is running, you can access the application in your browser at `http://localhost:3000`. Explore the features and functionalities of Coupit to see how it can transform your retail business.
